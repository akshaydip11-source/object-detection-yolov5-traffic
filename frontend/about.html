SafeCityAI case study

Object Detection with YOLOv5 for Traffic Enforcement

SafeCityAI is an AI-powered traffic enforcement application built around a custom YOLOv5 object detection model. The model detects Helmet, NoHelmet, and LicensePlate objects from traffic images and video.

The core problem

Manual review of traffic images and CCTV footage can be time-consuming. SafeCityAI uses computer vision to locate important traffic objects automatically and identifies NoHelmet detections as helmet-rule violations.

Detection classes
  • • Helmet
  • • NoHelmet
  • • LicensePlate
Tech stack
  • • Custom YOLOv5s model
  • • PyTorch inference
  • • OpenCV image and video processing
  • • FastAPI inference API
  • • SQLite application database
  • • JWT authentication
  • • HTML, CSS and JavaScript frontend
Dataset

The custom training dataset contains 500 traffic images prepared in YOLO format. The annotations were cleaned and remapped to the three project classes: Helmet, NoHelmet, and LicensePlate.

Project phases

Week 1 — Data preparation

Prepare traffic images, YOLO-format annotations, train/validation/test splits, and the three custom detection classes.

Week 2 — YOLOv5 training

Fine-tune YOLOv5s using transfer learning from pretrained weights and monitor precision, recall, loss, and mAP@0.5.

Week 3 — Inference

Run the trained model on unseen traffic images and video, apply confidence filtering, and generate annotated bounding-box results.

Week 4 — API and application

Integrate the trained model with FastAPI so uploaded images and videos can return structured detection results including class names, confidence scores, and bounding boxes.

Custom trained model

SafeCityAI uses the custom YOLOv5 model produced during training. The application loads the trained PyTorch checkpoint directly from: 

models/best.pt

Model classes: Helmet · NoHelmet · LicensePlate

Detection API

The FastAPI backend accepts traffic images and runs the custom YOLOv5 model. Each detection includes the class, confidence score, bounding-box coordinates, and violation information.
