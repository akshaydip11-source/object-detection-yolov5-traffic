Object Detection with YOLO for traffic enforcement

SafeCityAI is an internship prototype of the Object Detection with YOLOv5 AI project: annotate traffic data, train YOLO to spot Helmet, NoHelmet and LicensePlate, and expose an inference API — wrapped in a modern console for officers and city operators.

The core problem

Traffic police spend thousands of hours manually reviewing CCTV footage. SafeCityAI supports image, video and browser-frame review. Model predictions may be wrong and must not be treated as proof of an offence. No CCTV streams are connected.

Detection classes

  • • License plate region

  • • PDF e-challan + CSV export

Project phases (from brief)

Week 1 — Data curation

200–500 images, LabelImg/Roboflow annotation, YOLO txt labels, augmentation.

Week 2 — Model training

YOLOv5 transfer learning from COCO, hyp.yaml, monitor mAP@0.5.

Week 3 — Inference

Confidence thresholding, video streams, visual validation on unseen frames.

Week 4 — Deployment

Flask/FastAPI endpoint returning class, confidence, and bounding boxes as JSON.

Custom weights

Place your trusted custom YOLOv5 checkpoint at models/best.pt, or set MODEL_PATH. The checkpoint must contain Helmet, NoHelmet and LicensePlate. Missing or incompatible weights leave detection unavailable — no pretrained fallback is used.

See README.md for setup and validation. LicensePlate means bounding-box localization, not OCR. Accuracy and latency must be measured with the actual trained weights. Operational APIs require sign-in; media links expire. This remains an internship prototype, not a certified enforcement system.
