Object Detection with YOLO for traffic enforcement

SafeCityAI is a web prototype for the YOLOv5 traffic object-detection case study: annotate traffic images, train a detector for helmets, missing helmets, and license plates, then evaluate image and video inference through an API.

The core problem

Traffic police spend thousands of hours manually reviewing CCTV footage. The target custom model detects the three labeled classes in an image or video. The current public deployment uses a COCO-pretrained fallback and does not yet detect those custom classes.

Project phases (from brief)

Week 1 — Data curation

200–500 images, LabelImg/Roboflow annotation, YOLO txt labels, augmentation.

Week 2 — Model training

Fine-tune YOLOv5s from COCO weights and monitor validation mAP@0.5.

Week 3 — Inference

Confidence thresholding, video inference, and visual validation on held-out footage.

Week 4 — Deployment

FastAPI endpoint returns class, confidence, and bounding box coordinates as JSON.

Training status

The current deployment uses COCO-pretrained yolo11n.onnx as a general-object fallback. No annotated dataset or custom checkpoint is included, so the Helmet / No_Helmet / License_Plate model is not trained yet. After supplying the dataset, fine-tune YOLOv5s from COCO weights: 

python training/train_yolov5.py --validate-only
python training/train_yolov5.py --epochs 50 --batch 16
# Set MODEL_PATH=weights/yolov5_custom.onnx
# Set CLASS_NAMES_PATH=weights/traffic.names
