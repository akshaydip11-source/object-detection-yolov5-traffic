How SafeCityAI works

Four stages connect traffic input to an actionable detection and violation result.

Ingest

A traffic image or video is uploaded to the SafeCityAI FastAPI backend.

Detect

The custom YOLOv5 model performs inference at 640px resolution and returns class, confidence, and bounding-box coordinates.

Analyze

SafeCityAI identifies NoHelmet detections as traffic violations and prepares structured violation information.

Act

Results can be reviewed through the console, stored as violation records, and used within the digital challan workflow.

Computer vision pipeline

Transfer learning with YOLOv5 followed by application-level violation analysis.

CCTV / Upload → OpenCV Decode → Custom YOLOv5 → NMS + IoU → Violation Engine → Tickets · PDF · API JSON
Model

Custom YOLOv5s traffic detection model trained using transfer learning. The production model is stored as models/best.pt .
