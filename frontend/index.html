How SafeCityAI works

A custom-model workflow with explicit validation and review.

Ingest

CCTV snapshot, uploaded video, or live webcam frame hits the FastAPI gateway.

Detect

YOLOv5 best.pt runs preprocessing, inference and class-wise NMS with tunable confidence.

Enforce

NoHelmet predictions are flagged for manual review; detections are not proof of an offence.

Act

Signed-in demo officers may save image review records and export illustrative PDFs.

Computer vision pipeline

Transfer learning on COCO weights, fine-tune path for Helmet / NoHelmet / LicensePlate classes.

CCTV / Upload → OpenCV decode → Custom YOLOv5 → NMS + IoU → Violation engine → Tickets · PDF · API JSON
Model

Local YOLOv5 source with PyTorch CPU inference. Provide your trusted best.pt checkpoint; no fallback weights are included.

Metrics

Optimize for mAP@0.5. Confidence threshold slider in the console. Per-frame latency tracked on every job.
