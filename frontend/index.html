How SafeCityAI works

Four phases from the YOLOv5 traffic project, from data annotation through deployment.

Ingest

CCTV snapshot, uploaded video, or live webcam frame hits the FastAPI gateway.

Detect

YOLOv5s custom training target; current deployment uses the labeled YOLO11n COCO fallback.

Enforce

Training target: Helmet, No_Helmet, and License_Plate. The current fallback does not identify these custom classes.

Act

The web prototype can record detection jobs and review tickets. Custom-model enforcement requires trained weights.

Computer vision pipeline

Transfer learning on COCO weights for Helmet / No_Helmet / License_Plate classes.

CCTV / Upload → OpenCV decode → YOLOv5s training target → NMS + IoU → Violation engine → Tickets · PDF · API JSON
Model

Current deployed model: YOLO11n COCO fallback. Custom YOLOv5s weights require an annotated dataset and training run.

Metrics

Optimize for mAP@0.5. Confidence threshold slider in the console. Per-frame latency tracked on every job.
