How SafeCityAI works

Four phases from the original YOLOv5 traffic project — now productized end-to-end.

Ingest

CCTV snapshot, uploaded video, or live webcam frame hits the FastAPI gateway.

Detect

YOLO11n ONNX runs letterbox → inference → class-wise NMS with tunable confidence.

Enforce

Heuristics + custom classes flag helmet, seatbelt, triple-riding & signal risks.

Act

Tickets land in the queue. Officers review, issue PDF challans, and track payment.

Computer vision pipeline

Transfer learning on COCO weights, fine-tune path for Helmet / NoHelmet / LicensePlate classes.

CCTV / Upload → OpenCV decode → YOLO11n ONNX → NMS + IoU → Violation engine → Tickets · PDF · API JSON
Model

YOLO11n (nano) via ONNX Runtime — edge-friendly, CPU inference, deployment-ready best.pt swap-in for custom traffic weights.

Metrics

Optimize for mAP@0.5. Confidence threshold slider in the console. Per-frame latency tracked on every job.
